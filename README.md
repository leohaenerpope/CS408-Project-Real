# NBA Player Matchup Notes App

This is a NBA Player Matchup Notes Tracker. Users are able to create players with names, and then create matchup notes for the players against other existing players. Users can track different stats about how players do against each other on specific dates, including points, assists, rebounds, general notes. As of now, the database system is universal (no account system, just a global database) so users share their information with others.

See documentation for Tech stack information and documentation.
